# 🌍 Travel One

**Every Journey. One Solution.**

Travel One is an AI-powered travel planning web application developed for the **AI FOR EVERYDAY LIFE Hackathon 2026**.

The application helps travelers organize an entire trip in one place with the support of **AIO**, an intelligent AI travel assistant.

---

## ✨ Features

- 🧳 Personalized Trip Planning
- 📍 Places & Dining Recommendations
- 🌐 Real-time Translation
- 🏨 Hotel Recommendations
- 🏧 Smart ATM Recommendation
- 💵 Cash Recycler (TCR) Locator

---

## 🤖 AI Integration

Travel One integrates **Google Gemini AI** to power **AIO**, enabling users to:

- Generate travel suggestions
- Answer travel-related questions
- Provide personalized recommendations
- Assist throughout the journey

---
